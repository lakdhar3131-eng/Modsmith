# RUXX — Primary Stacked Logo (Ornate Peacock)

The full primary logo: ornate peacock/mandala **R** emblem on top, **RUXX**, tagline below.
Matches the detailed reference design.

| File | Format | Use |
|------|--------|-----|
| `ruxx-logo-primary.svg` | SVG (vector text; emblem embedded) | Master — scale to any size, print, `.ai`/`.eps`/`.pdf` export |
| `ruxx-logo-primary.png` | PNG (1200×1500) | Web, slides, social |
| `ruxx-logo-primary.ico` | ICO (16→256px) | Browser favicon |

White on solid black. For light surfaces use the inverted variant in `../svg/ornate-logo-primary-light.svg`.

> Note: the emblem in the `.svg` is embedded as a high-resolution image (the
> detailed mandala is raster art); the **RUXX** wordmark and tagline are real
> vector text.
