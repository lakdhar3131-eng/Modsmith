# RUXX — R Emblem / Monogram (Ornate Peacock)

The standalone ornate peacock/mandala **R**, no text. Best for app icons, avatars, and monograms.

| File | Format | Use |
|------|--------|-----|
| `ruxx-r-emblem.svg` | SVG (embedded high-res image) | Master — scale, print, `.ai`/`.eps`/`.pdf` export |
| `ruxx-r-emblem.png` | PNG (1024×1024) | App icons, avatars, social |
| `ruxx-r-emblem.ico` | ICO (16→256px) | Browser favicon |

White ornate peacock R on solid black. For small browser-tab sizes use the
simplified `favicon.ico` in the `ico/` folder.

> The detailed mandala is raster art (AI-generated), so the SVG embeds it as a
> high-resolution image rather than pure paths.
