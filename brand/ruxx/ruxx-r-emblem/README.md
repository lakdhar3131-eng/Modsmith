# RUXX — R Emblem (Monogram)

The standalone mandala **R**, no text. Best for app icons, avatars, and monograms.

| File | Format | Use |
|------|--------|-----|
| `ruxx-r-emblem.svg` | SVG (vector) | Master — scale to any size, print, .ai/.eps/.pdf export |
| `ruxx-r-emblem.png` | PNG (512×512) | App icons, avatars, social |
| `ruxx-r-emblem.ico` | ICO (16→256px) | Browser favicon |

White mandala-filled **R** on solid black. For small browser-tab sizes use the
simplified `../ico/favicon.ico`.
